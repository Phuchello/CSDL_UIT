## 2. Tổng Hợp Cấu Trúc Nội Dung & Đề Cương Môn Học IT004

### 2.1 Thông tin tổng quan học phần

- **Tên tiếng Việt:** Cơ sở dữ liệu

---

### 2.2 Cấu trúc chương trình học (Chương & Tuần học)

Chương trình học gồm 6 chương lý thuyết chính kết hợp chuỗi bài tập thực hành trên máy:

| Chương | Tên chương / Chủ đề | Nội dung trọng tâm |
| :--- | :--- | :--- |
| **Chương 1** | Tổng quan về Hệ Cơ sở dữ liệu | Khái niệm CSDL, Hệ quản trị CSDL (DBMS), so sánh với Hệ tập tin (File System), kiến trúc 3 mức (Trong, Ngoài, Khái niệm), tính độc lập dữ liệu. |
| **Chương 2** | Mô hình dữ liệu Quan hệ & ER | Mô hình Thực thể - Mối kết hợp (ERD), thực thể, thuộc tính, mối quan hệ, cấp quan hệ; Quy tắc chuyển đổi lược đồ ERD sang Lược đồ quan hệ (Relational Schema). |
| **Chương 3** | Ngôn ngữ Đại số Quan hệ | Khái niệm Quan hệ, Thuộc tính, Bộ (Tuple), Miền giá trị; Các phép toán đại số quan hệ: Chọn ($\sigma$), Chiếu ($\pi$), Hợp ($\cup$), Giao ($\cap$), Trừ ($-$), Tích Cartesian ($\times$), Kết ($\bowtie$), Chia ($\div$). |
| **Chương 4** | Ngôn ngữ Truy vấn SQL | - **DDL:** `CREATE TABLE`, `ALTER TABLE`, `DROP TABLE`, định nghĩa khóa chính/khóa ngoại.<br>- **DML:** `INSERT`, `UPDATE`, `DELETE`.<br>- **DQL:** Phép truy vấn `SELECT` với `WHERE`, `GROUP BY`, `HAVING`, `ORDER BY`, phép nối (`INNER/LEFT/RIGHT JOIN`), truy vấn con (Subquery), Khung nhìn (`VIEW`). |
| **Chương 5** | Ràng buộc Toàn vẹn (RBTV) | Khái niệm RBTV, phân loại (Miền giá trị, Liên thuộc tính, Liên quan hệ, Khóa); Xây dựng Bảng tầm ảnh hưởng (Effect Table) cho các thao tác Thêm, Xóa, Sửa (`INSERT`, `DELETE`, `UPDATE`); Cài đặt RBTV bằng SQL (Constraint, Trigger). |
| **Chương 6** | Lý thuyết Thiết kế CSDL (Phụ thuộc hàm & Dạng chuẩn) | Khái niệm Phụ thuộc hàm (FD), Hệ tiên đề Armstrong, Bao đóng của tập thuộc tính ($X^+$), Phủ tối thiểu; Các dạng chuẩn: 1NF, 2NF, 3NF, BCNF; Thuật toán phân rã lược đồ quan hệ bảo toàn thông tin và bảo toàn phụ thuộc hàm. |

---

### 2.3 Cấu trúc Thực hành (Lab Structure)
Nội dung thực hành được thiết kế theo 2 CSDL bài mẫu xuyên suốt học kỳ: **Quản lý Bán hàng** và **Quản lý Giáo vụ**.

- **Lab 1:** Cài đặt MS SQL Server, SSMS. Dùng ngôn ngữ DDL để tạo bảng, khai báo khóa chính (Primary Key), khóa ngoại (Foreign Key) và ràng buộc cơ bản.
- **Lab 2:** Nhập dữ liệu mẫu (DML `INSERT`), cập nhật dữ liệu (`UPDATE`, `DELETE`). Viết các câu lệnh truy vấn SQL đơn giản đến trung bình (phép chọn, chiếu, kết nối nhiều bảng).
- **Lab 3:** Truy vấn SQL nâng cao: Phép gom nhóm (`GROUP BY`, `HAVING`), hàm hợp nhóm (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`), truy vấn con (Subquery), phép chia trong SQL.
- **Lab 4:** Thiết lập ràng buộc toàn vẹn nâng cao bằng `CHECK CONSTRAINT`, `RULE`, và viết `TRIGGER` trên MS SQL Server.
- **Lab 5:** Lập trình trong SQL Server: Thủ tục lưu trữ (`STORED PROCEDURE`), Hàm thủ công (`FUNCTION`), Giao dịch (`TRANSACTION`).

### 3.2 Cấu trúc Đề thi Giữa kỳ (Thi tự luận - 60 đến 90 phút)
Thi giữa kỳ thường tập trung vào 4 nội dung đầu của chương trình:
1. **Bài tập Thiết kế Mô hình ERD:** Cho bài toán thực tế (Quản lý thư viện, Quản lý khách sạn, Quản lý bán hàng...), vẽ sơ đồ ERD đầy đủ thực thể, thuộc tính và mối quan hệ.
2. **Chuyển đổi ERD sang Lược đồ Quan hệ:** Chuyển đổi chính xác các tập thực thể và mối quan hệ (1-1, 1-N, N-M) sang dạng bảng, chỉ rõ khóa chính và khóa ngoại.
3. **Biểu diễn Phép truy vấn bằng Đại số Quan hệ:** Viết các biểu thức đại số quan hệ cho các yêu cầu truy vấn dữ liệu.
4. **Viết câu lệnh SQL DDL/DML:** Tạo bảng có khóa, hoặc viết 3-5 câu truy vấn SQL cơ bản/nâng cao.

---

### 3.3 Cấu trúc Đề thi Cuối kỳ (Thi Lý thuyết + Thi Thực hành)

#### A. Thi Lý thuyết Cuối kỳ (Tự luận - 90 phút)
Đề thi gồm 4 - 5 câu lớn bao quát toàn bộ chương trình:
1. **Câu Phụ thuộc hàm & Bao đóng:** Tính bao đóng $X^+$, tìm tất cả các khóa của lược đồ quan hệ $R(U, F)$.
2. **Câu Dạng chuẩn & Phân rã:** X định dạng chuẩn của lược đồ quan hệ (1NF, 2NF, 3NF, BCNF); thực hiện phân rã lược đồ quan hệ về dạng chuẩn 3NF hoặc BCNF bảo toàn thông tin.
3. **Câu Ràng buộc Toàn vẹn & Bảng tầm ảnh hưởng:** 
   - Phát biểu điều kiện ràng buộc toàn vẹn bằng ngôn ngữ tự nhiên và ký hiệu toán học/đại số quan hệ.
   - Lập Bảng tầm ảnh hưởng (Effect Table) chi tiết cho 3 thao tác `INSERT`, `DELETE`, `UPDATE` trên các quan hệ liên quan.
4. **Câu Đại số Quan hệ & SQL Nâng cao:** Viết biểu thức đại số quan hệ và câu lệnh SQL cho các truy vấn phức tạp (gom nhóm, phụ thuộc tồn tại `EXISTS`, truy vấn con lồng nhau, phép chia).

#### B. Thi Thực hành Cuối kỳ (Thi trên máy - 60 đến 90 phút)
Thi trực tiếp trên MS SQL Server (không dùng internet/tài liệu giấy):
1. **Tạo CSDL & Bảng:** Viết script SQL tạo các bảng, khai báo khóa chính, khóa ngoại, ràng buộc duy nhất/miền giá trị.
2. **Thao tác Dữ liệu:** Viết script `INSERT`/`UPDATE` theo dữ liệu đề thi.
3. **Truy vấn SQL:** Viết 8 - 10 câu truy vấn từ cơ bản đến phức tạp (có `GROUP BY`, `HAVING`, `NOT EXISTS`, phép chia).
4. **Viết Stored Procedure / Trigger:** Viết 1 - 2 Trigger kiểm tra ràng buộc toàn vẹn phức tạp hoặc Stored Procedure xử lý nghiệp vụ.
