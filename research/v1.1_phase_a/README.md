## Executive summary

This pass searched Vietnamese and English sources for IT004 course scope, exam patterns, practical SQL Server skills, and a Quartz-style Knowledge Garden. It covered official UIT portals and notices, Microsoft Learn, recognized textbooks, the current repository corpus, multiple GitHub repositories, Studocu, Scribd, and SVUIT.

The strongest evidence is official UIT curriculum/catalogue data, the official 2024–2025 practical-exam notice, the historical 2014 practical notice, the UIT library’s IT004 textbook mapping, and primary Microsoft documentation. Dated student repositories and community previews reveal useful patterns but are Tier C/D evidence only. No rights-cleared official question-paper set was found.

Uncertainties are concentrated in question-level exam frequency, Chapter 6 frequency, missing semester/year coverage, and redistribution rights for community scans. The public tree also contains historical research ledgers that reference local source files no longer present in the public checkout.

Recommended next phase: human approval of the source ledger, provenance rules, practical scope, essay taxonomy, and one of the proposed cover directions. Only then should implementation begin.

## Rules used

- Tier A: official UIT, Microsoft, or major textbook.
- Tier B: strong-provenance archived course/exam material.
- Tier C: student repository, gist, Studocu, Scribd, or community page.
- Tier D: unverified or questionable material.
- No C/D source is sole authority for an academic claim.
- `verified-exam` is reserved for provenance-confirmed, short paraphrases; otherwise use `exam-pattern` or `original`.
- Copyrighted scans and long exam reproductions are link-only references.
