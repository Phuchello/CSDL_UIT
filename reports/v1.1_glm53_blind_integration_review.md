## 3. Academic Correctness Audit

### 3.1 Relational Algebra & Division ($R \div S$)
- **Theory Book (`ch03_relational_algebra.html` L290–306):**
  - Formal definition: $R(X,Y) \div S(Y) = \{ x \mid \forall y \in S, (x,y) \in R \}$.
  - Fundamental reduction: $R \div S = \pi_X(R) - \pi_X((\pi_X(R) \times S) - R)$.
  - Exact property: When $S = \emptyset$, $(\pi_X(R) \times \emptyset) - R = \emptyset$, so $R \div \emptyset = \pi_X(R)$.
- **Knowledge Garden (`garden/content/theory/division.md`):**
  - Classical empty-set theorem: $R \div \emptyset = \pi_X(R)$ explicitly stated and proven.
  - SQL distinction: Clearly separates the attribute set $X$ of relation $R$ from an independent candidate table $C$ (`tr_students`). Explains that in SQL, `WHERE NOT EXISTS (SELECT 1 FROM Required WHERE NOT EXISTS (SELECT 1 FROM Evidence ...))` returns all candidates $\pi_{\text{StudentId, FullName}}(C)$ when $S = \emptyset$.
  - Aggregation alternative: Correctly includes `JOIN dbo.RequiredCourses` to restrict evidence, and qualifies the empty-set failure so it is not claimed when the candidate domain itself is empty.
- **Verdict:** **ACADEMICALLY RIGOROUS & UNIFIED.**

### 3.2 SQL Universal Query & Correlated Subqueries
- **Practice Handbook (`04_aggregation_and_subqueries.html` & `11_lab03_advanced.html`):**
  - Step-by-step 3-step mental translation:
    1. Outer candidate domain: Sinh viên $s \in \text{tr\_students}$.
    2. Divisor requirement: Môn học $c \in \text{tr\_courses}$.
    3. Evidence check: Kết quả $r \in \text{tr\_results}$ với $r.\text{StudentId} = s.\text{StudentId} \land r.\text{CourseId} = c.\text{CourseId}$.
- **Live SQL Server Execution:** Query A04 executed on live SQL Server 2025; deterministically returns exactly one row: `S001 - Hà Nguyễn`. Query A05 (`COUNT(DISTINCT)`) also returns `S001`.
- **Verdict:** **PASS.**
