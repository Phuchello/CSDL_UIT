7.1 Tổng quan môi trường

IT004 sử dụng Microsoft SQL Server làm HQTCSDL thực hành. Bạn cần:

  • SQL Server — engine xử lý dữ liệu (cài bản Developer hoặc Express — miễn phí)
  • SQL Server Management Studio (SSMS) — giao diện đồ họa để làm việc với SQL Server
🧠 Mental Model — SQL Server = Bếp, SSMS = Nhà bếp

SQL Server là bếp (nơi nấu/xử lý dữ liệu). SSMS là nhà bếp (nơi bạn đứng, có dao thớt, bảng điều khiển). Bạn viết lệnh SQL trên SSMS → SSMS gửi xuống SQL Server → SQL Server thực thi → trả kết quả lên SSMS.

7.2 Cài đặt SQL Server & SSMS

Tải SQL Server: Vào https://www.microsoft.com/en-us/sql-server/sql-server-downloads. Chọn bản Developer (miễn phí, đầy đủ tính năng) hoặc Express (nhẹ hơn).
Cài đặt SQL Server: Chạy installer → chọn "Basic" installation → chờ hoàn tất. Ghi nhớ Server Name (thường là localhost hoặc .\SQLEXPRESS).
Tải SSMS: Tìm "SSMS download" trên Microsoft Learn → tải bản mới nhất → cài đặt.
Kết nối: Mở SSMS → nhập Server Name → chọn "Windows Authentication" → Connect.
⚠ BẪY — Lỗi kết nối phổ biến
  • "Cannot connect to server": Kiểm tra SQL Server service đã chạy chưa (Services → SQL Server → Start)
  • Sai Server Name: Thử localhost, ., .\SQLEXPRESS, hoặc (localdb)\MSSQLLocalDB
  • Authentication fail: Dùng Windows Authentication nếu không đặt SA password

7.3 Tạo Database từ script

Trong IT004, giảng viên cung cấp file .sql chứa cả DDL (tạo bảng) và DML (thêm dữ liệu). Workflow:

Tạo database mới: Trong SSMS, chuột phải "Databases" → "New Database" → nhập tên (vd: QLGV) → OK.
Mở file SQL: File → Open → File → chọn file .sql được cung cấp.
Chọn đúng database: Ở dropdown phía trên, chọn database vừa tạo (QLGV). Nếu quên bước này, lệnh sẽ chạy trên database sai!
Thực thi: Nhấn F5 hoặc nút "Execute" → kiểm tra kết quả ở tab Messages.
Kiểm tra: Expand database → Tables → kiểm tra các bảng đã tạo → chuột phải → "Select Top 1000 Rows" để xem dữ liệu.

Ví dụ: Tạo database QLGV

-- Bước 1: Tạo database
CREATE DATABASE QLGV;
GO

-- Bước 2: Chuyển sang database vừa tạo
USE QLGV;
GO

-- Bước 3: Tạo bảng KHOA
CREATE TABLE KHOA (
    MAKHOA  NVARCHAR(4),
    TENKHOA NVARCHAR(40),
    NGANH   NVARCHAR(30),
    TRUONGKHOA CHAR(4),
    CONSTRAINT pk_KHOA PRIMARY KEY (MAKHOA)
);

-- Bước 4: Thêm dữ liệu
SET DATEFORMAT DMY;

7.8 Pattern từ bài lab IT004

Phân tích từ các file SQL thực hành, những pattern phổ biến:

Lab 1–2: DDL + DML cơ bản

-- Tạo bảng với PK/FK
CREATE TABLE HOADON (
    SOHD    INT,
    NGHD    SMALLDATETIME,
    MAKH    CHAR(4),
    MANV    CHAR(4),
    TRIGIA  MONEY,
    CONSTRAINT pk_hd PRIMARY KEY(SOHD)
);
ALTER TABLE HOADON ADD CONSTRAINT fk01_HD
    FOREIGN KEY(MAKH) REFERENCES KHACHHANG(MAKH);

Lab 3–4: SELECT + JOIN + GROUP BY

-- Đếm số hóa đơn của mỗi khách hàng trong năm 2006
SELECT KH.MAKH, KH.HOTEN, COUNT(HD.SOHD) AS SoHD
FROM KHACHHANG KH
JOIN HOADON HD ON KH.MAKH = HD.MAKH
WHERE YEAR(HD.NGHD) = 2006
GROUP BY KH.MAKH, KH.HOTEN;

Lab 5–6: Subquery + NOT EXISTS + Trigger

-- Tìm khách hàng đã mua TẤT CẢ sản phẩm Việt Nam
SELECT KH.MAKH, KH.HOTEN
FROM KHACHHANG KH
WHERE NOT EXISTS (
    SELECT * FROM SANPHAM SP
    WHERE SP.NUOCSX = 'Viet Nam'
    AND NOT EXISTS (
        SELECT * FROM CTHD CT
        JOIN HOADON HD ON CT.SOHD = HD.SOHD
        WHERE HD.MAKH = KH.MAKH
        AND CT.MASP = SP.MASP
    )
);
🔗 Connection

Query "tất cả" ở trên là SQL tương đương của phép chia (Division) trong ĐSQH (Chương 3, mục 3.9). Đây là double NOT EXISTS pattern — pattern quan trọng nhất cho cả thi lý thuyết lẫn thực hành.
