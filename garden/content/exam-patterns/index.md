# Exam patterns

Tổng hợp 4 dạng bài trọng tâm được quan sát qua hệ thống đề thi giữa kỳ, cuối kỳ và thực hành máy IT004 UIT (chi tiết mức độ tin cậy và provenance xem tại [[sources/index|Sources]]):

- [[exam-patterns/relational-algebra|Observed pattern — relational algebra]]: Phép chọn, chiếu, kết, trừ và phép chia trong Đại số quan hệ.
- [[exam-patterns/sql-reasoning|Observed pattern — SQL reasoning]]: Bẫy logic 3 trị (3VL), NULL, NOT IN và kỹ thuật Double NOT EXISTS.
- [[exam-patterns/normalization|Observed pattern — normalization]]: Chuỗi thuật toán tìm bao đóng, khóa ứng viên, phủ tối thiểu và chuẩn hóa dạng chuẩn.
- [[exam-patterns/rbtv-trigger|Observed pattern — RBTV and trigger]]: Bảng tầm ảnh hưởng và cài đặt trigger tập hợp đa dòng.
